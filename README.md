# Data Analytics Portfolio

Подборка проектов по анализу данных, продуктовой аналитике и машинному обучению.

В проектах использованы Python, SQL, pandas, NumPy, scikit-learn, PCA, t-SNE, KMeans, DBSCAN, когортный анализ и собственные реализации ML-алгоритмов.

## Data Analytics

### E-commerce Product Analytics

Анализ данных бразильского e-commerce Olist: заказы, выручка, средний чек, повторные покупки, доставка, отзывы и удержание пользователей.

**Инструменты:** SQL, Python, pandas, cohort analysis, retention.

[Открыть проект →](https://github.com/ulko31/ecommerce-product-analytics)

---

### Customer Segmentation

Сегментация клиентской базы с помощью KMeans и DBSCAN.

В проекте выполнены предобработка данных, стандартизация признаков, PCA, подбор числа кластеров и интерпретация клиентских сегментов.

**Инструменты:** Python, pandas, scikit-learn, PCA, KMeans, DBSCAN.

[Открыть проект →](https://github.com/ulko31/customer-segmentation-kmeans-dbscan)

---

### Customer Behaviour & Dimensionality Reduction

Исследование структуры клиентских данных и поведения пользователей с использованием методов снижения размерности.

В проекте применены PCA и t-SNE, проведена проверка пригодности данных для факторизации и анализ наиболее значимых признаков.

**Инструменты:** Python, pandas, PCA, t-SNE, KMO, Bartlett test.

[Открыть проект →](https://github.com/ulko31/customer-behaviour-dimensionality-reduction)

## Machine Learning

### Weather Prediction ML

Модель для оценки ощущаемой температуры по данным Open-Meteo.

Реализованы собственная многомерная линейная регрессия и градиентный спуск, пайплайн обучения, метрики MAE / RMSE / R² и Flask-интерфейс.

**Результат:**  
MAE — 0.408 °C  
RMSE — 0.546 °C  
R² — 0.9977

**Инструменты:** Python, NumPy, pandas, scikit-learn, Flask, Open-Meteo API.

[Открыть проект →](https://github.com/ulko31/weather-prediction-ml)

### Housing Price Regression

Полиномиальная регрессия для оценки стоимости жилья на данных Boston Housing.

Модель реализована с нуля: градиентный спуск, стандартизация, полиномиальные признаки, собственные RMSE и R², подбор гиперпараметров и автоматические тесты.

**Инструменты:** Python, NumPy, pandas, scikit-learn, unittest.
